**Compose additions**: `clamav` and `worker-docs` (see the master plan's startup table). `worker-docs` is attached only to an internal Compose network (`internal: true`) that reaches PostgreSQL, MinIO, Temporal and the ClamAV socket volume and has no route to the internet. Each parse runs in a child process with no network namespace, a seccomp profile, a memory limit and a timeout, so a parser compromise cannot reach even the internal services.

**Paid or account-based options stay opt-in**: Brave Search, Tavily, Exa, SerpAPI, OpenCorporates, Crunchbase, PitchBook, commercial sanctions data. None is required by any domain gate.
